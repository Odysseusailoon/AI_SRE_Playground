## 🚨 缺失镜像分析

### Astronomy Shop 镜像 (⚠️ 完全缺失)

由于 Astronomy Shop 使用 Helm Chart 部署，镜像列表动态生成，建议：

1. **方案1：预先拉取**
```bash
# 从 Helm Chart values.yaml 提取镜像列表
helm show values open-telemetry/opentelemetry-demo > values.yaml
grep "repository:" values.yaml | awk '{print $2}' > astronomy_images.txt

# 批量拉取
while read image; do
    docker pull $image
    kind load docker-image $image --name kindXX
done < astronomy_images.txt
```

2. **方案2：允许联网**
- Astronomy Shop 任务运行时允许集群联网
- 仅在运行 `astronomy_shop_*` 任务时开启网络
- 其他任务保持离线

3. **方案3：缓存Chart**
```bash
# 下载完整 Chart 到本地
helm pull open-telemetry/opentelemetry-demo --untar
# 修改 values.yaml，指定本地镜像仓库
```
