## 📍 镜像存储位置说明

### 1. **宿主机 Docker** (`docker images`)
- 所有镜像最初存储在这里
- 使用 `kind load docker-image` 可以将镜像复制到 kind 集群内

### 2. **kind 集群内** (`docker exec kind-xxx-control-plane crictl images`)
- 每个 kind 集群独立存储镜像
- 创建新集群时需要重新加载镜像
